Report image positions, not data values: for each marker, `x` and `y` are the
position of the marker centre in relative image coordinates from 0 to 1000:
x = 0 at the left edge and 1000 at the right edge, y = 0 at the top edge and
1000 at the bottom edge. The axis calibration is done separately by a person,
so you do not need to read the axes or the tick labels.
