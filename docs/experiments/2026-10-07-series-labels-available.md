# 正解データに系列名を入れられる(2026-10-07)

オーナー指摘「starrydata の dataset のサンプル名を使えば正解データ作れると思いますよ」を確認した。
**指摘は正しい。系列名はソースにあり、こちらのパーサが捨てていた。**

## 使うべきフィールドは `sample_name` である(`composition` ではない)

最初 `*_curves.csv` の `composition` を使ったが、**これは誤りだった**。
採点対象 94 図のうち **45 図(48%)は全曲線が同じ公称組成**で、違うのは合成条件だけである。

```
1527: Pb 系が4本。composition は4本とも同じ。違うのはホットプレス温度
```

`composition` では区別できず、控えに使った `sample_id` は DB の内部番号なので図のどこにも現れない。
オーナーが最初に開いた 29160 がまさにこれで、`Bi0.5Sb1.5Te3 #37266` / `#37267` という
**照合しようのないラベル**を出していた。

**`*_samples.csv` の `sample_name` が正解だった。**

```
1527 (4曲線): HP680, HP720, HP760, HP800
1531 (4曲線): SPS680, SPS720, SPS760, SPS820
```

HP = hot press、SPS = spark plasma sintering、数字は温度。**図の凡例に印字されている文字列そのもの**で、
45 図すべてを区別できた(残り 0)。図を読んでいる抽出手法の出力と突き合わせられる唯一の名前である。

## 対応づけの実装(2つの罠)

`attach_series_labels.py` は figure_id の中で正解曲線 ↔ CSV 行を対応づける。素朴な
x 値の一致では通らない。

1. **x だけを鍵にすると潰れる。** 同じ温度点で測った複数試料が1図内によくあるので、
   `(x, y)` を鍵にする。
2. **2.6 の単位移行で値に係数が掛かっている**(8724: K → °C)。単位変換は一次変換なので、
   x と y をそれぞれ 0〜1 に正規化すれば形は不変。正規化した点列が一致する組を
   ハンガリアン法で 1 対 1 に割り当てる。さらに **y が log10 に移っている図**(51437)は
   一次変換ではないので、CSV 側の log10 も試す。
3. **許容幅は実測で決めた。** 正解側の y は 6 桁に丸められている(29160 の
   `0.854676` に対し公開値は `0.8546756`)。94 図で測ると、正しい組の形距離は
   中央値 1e-16 / p90 4e-16 で、次に大きいのは 0.24 まで飛ぶ。間の **1e-5** に置いた。
   2番目の候補も許容内に入る曲線は `ambiguous` として人の確認に回す。

結果(140 図 / 549 曲線): `sample_name` が付いたのが **98.4%**、未一致 1.6%、
形が曖昧なもの 28 曲線。採点対象 94 図では名前なし・重複ともに 0。

**採点値は動かない**(採点は x / y しか見ない)。Opus 5.5 の保存済み実行で、
図ごとの点指標が 1 件も動かないことを確認済み。

## これで何ができるようになるか

1. **7.2 の限界(系列対応づけがラベルを使っていない)が解消できる。** 幾何だけの対応づけと
   ラベルを使う対応づけを比較できる。
2. **ラベルを見る指標が計算できる。** CHART-Infographics Task 6b は系列名の編集距離を
   コストに含む(3.5.3)。我々の側に名前がなく `name` 項を評価できていなかった。
3. **RMS が計算できる。** RMS の列見出しは系列名、行見出しは x の値である。前者が無かった。

## 確認の手順

`sample_name` を機械的に付けただけなので、**どの曲線がどの試料かは形の一致で機械が決めている**。
図の凡例と突き合わせる確認が要る。`generate_series_label_review.py` がその確認ページを作る。

ページは3枚組で、**1枚目が決め手**である:

1. **元の図の上に、正解点と試料名を直接重ねたもの。** 色・マーカー・線種は
   `sample_curve_styles.py` が軸校正を使って**元の図の画素から読んだ**もの。凡例と直接照らせる
2. 元の図(凡例の原本)
3. 正解データを同じ色・マーカー・線種で描き直したもの

判定はアーティファクトの `db` に保存されるので、そのまま読み戻せる。

色の採取は確認した範囲で全曲線一致した。**マーカーの形は約 75%** なので、ページでは推定と明示している。
