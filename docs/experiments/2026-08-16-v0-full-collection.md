# 2026-08-16 Phase 3本収集: 熱電材料コーパス全量(CC-BY確定分)

- Status: done
- 関連設計: [`docs/design/benchmark-architecture.md`](../design/benchmark-architecture.md) §7.9〜§7.13
- 再現スクリプト: [`scripts/collect/collect_v0_dataset.py`](../../scripts/collect/collect_v0_dataset.py)
- 出力: [`data/manifest/v0/`](../../data/manifest/v0/)(`papers.json` / `figures.json` / `curves.json` / `summary.json`。CC BY 4.0、コミット対象)。画像・PDFは`data/raw/`(gitignore対象、ローカルのみ)

## 目的

司令塔承認(2026-08-16)に基づき、Phase 2/3パイロットで検証済みのパイプラインを
ThermoelectricMaterials全論文(9,484件)に対して実行し、v0データセットのground truth
manifestおよび画像コレクションを本番規模で確保する。

## 手順

1. 全9,484論文をOpenAlexへバッチ問い合わせ(40件/バッチ、0.3秒間隔)しライセンス分類。
   結果は`data/cache/openalex_license.json`にキャッシュ(再実行時の再問い合わせを回避)
2. `classify_license`でREDISTRIBUTABLEと判定された論文全件(603件)についてground truth
   manifestを構築(PDF取得の成否と独立)
3. `pdf_url`を持つ論文についてPDF取得(0.5秒間隔、単一スレッド、タイムアウト20秒)→
   図候補抽出。20論文ごとにmanifestをチェックポイント書き出し

## 実行中に発見・修正したバグ

**DOI大文字小文字不一致によるKeyError**(603件中400件処理した時点でクラッシュ)。
OpenAlexはレスポンスのDOIを独自の正規化(小文字化)で返すことがあり、Starrydata CSV側の
元表記(大文字混じり)と一致しないケースが存在した(例: 発生箇所の実DOIは
`10.24425/bpasts.2020.131835`)。パイロット規模(30〜50件)では偶然発生しなかったが、
603件規模で顕在化。**全DOIキーを小文字に正規化**して修正し、あわせて**再開可能性
(処理済みSIDをスキップしてmanifestに追記)**をスクリプトに追加(クラッシュ時に
既取得分を再取得しない=出典サーバーへの不要な再アクセスを避ける礼儀の一環)。
修正後、400件の既存チェックポイントから再開し、残り203件を約5分で完走した。

## 結果

### 全体

| 指標 | 値 |
|---|---|
| REDISTRIBUTABLE論文(全量) | 603 / 9,484(6.36%。Phase 2の500件サンプル推計6.0%とほぼ一致) |
| ground truthを確保できた論文 | 603 / 603(**100%**) |
| FigureRecord | 2,555 |
| GroundTruthCurve | **10,057** |
| うちheld-out split | 464 figures(18.2%、目標20%に近似。ハッシュベースの決定的割当のため厳密20%ではない) |

### 画像コレクション

| 指標 | 値 |
|---|---|
| `pdf_url`を持つ論文 | 527 / 603(87.4%) |
| 画像抽出に成功した論文 | **179 / 527**(pdf_url保有分の**34.0%**) |
| 全REDISTRIBUTABLE論文に対する画像確保率 | 179 / 603(**29.7%**) |
| 抽出画像総数 | 2,458枚(1論文平均13.7枚、Phase 3パイロットの14.5枚とほぼ一致) |

**Phase 3パイロット(29件)との比較**: パイロットのPDF取得成功率37.9%に対し、本収集の
pdf_url保有分ベースでの成功率は34.0%とやや低い(小規模サンプルの偶然のばらつきの範囲内)。
全REDISTRIBUTABLE論文ベースでは29.7%が画像付きペアを確保できる計算となり、
§7.11で見積もった「200〜230論文相当」という予測は実測(179論文)と近い(やや下振れ)。

## v0データセットの現状(2階層構成、§7.11の方針通り)

- **Tier 1(ground truth manifest、全量)**: 603論文・2,555 figure・10,057曲線。CC BY 4.0。
  `data/manifest/v0/`にコミット済み
- **Tier 2(画像ペア確保済みサブセット)**: 179論文相当。画像自体(546MB)はリポジトリに
  コミットしない方針(design §6)のため、`data/raw/images/`にローカル保存のみ
  (再現はスクリプト実行で可能)。将来的にどこにホストするか(Figshare/HuggingFace Hub等)
  は司令塔確認事項
