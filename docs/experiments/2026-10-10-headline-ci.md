# 見出し数値の bootstrap 95% 信頼区間(2026-10-10)

MRS 要旨で使う見出し数値に信頼区間をつけた。コミット済みの `results/*.json` の図ごとの点 F1 だけから計算しており、モデルの再実行はしていない。

- 対象: 密でない77図、点 F1(macro)、τ = 0.02。条件は `v0-eval-pilot-n91-noaxis`(完全自動)と `v0-eval-pilot-n91-pixcal`(人が軸を校正)。
- 方法: パーセンタイル bootstrap、10,000 回、乱数シード 0。`scripts/eval/headline_ci.py`(テスト `tests/scripts/test_headline_ci.py`)。
  - 図単位: 図を独立に復元抽出する。同じ論文の図が似ている分、区間は狭すぎる可能性がある。
  - 論文単位(クラスター): 論文を復元抽出し、選ばれた論文の全図を使う(統計量は図の平均のまま)。論文は `figure_id` の先頭(Starrydata の paper id)。
- 77図は **21 本の論文**から来ている(約29本という数は、密な14図を含む91図全体の本数と思われる)。
- 差は pixcal − noaxis。両条件で同じ77図を対にしている。
- 点推定は 4.1 / 4.2 の表と一致する(`check_paper_numbers.py` は食い違い 0 件)。

## 読み取り

- 区間が 0 を含まない校正の効果は、Sonnet 5.5(+0.032、論文単位でも [+0.008, +0.066])と GPT-6.1-Sol(−0.114、論文単位 [−0.154, −0.076])の2つだけ。
  Opus 5.5、Fable 5.1、Haiku 4.5 の差は 0 と区別できない。
- 論文単位にすると多くの区間が広がる(Sonnet の完全自動 [0.921, 0.973] → [0.909, 0.974]、Qwen3.8-27B [0.858, 0.960] → [0.835, 0.967])。結論は変わらない。
- Sonnet の差は +0.032(0.9812 − 0.9489 = 0.0323)。4.2 読み取り1の「0.031」は古い値だったので 0.032 に直した。
- Qwen3.8-27B Q4 の論文単位の区間 [0.835, 0.967] は GPT-6.1-Sol の校正あり [0.810, 0.911] と重なる。
  4.2 読み取り5の「GPT-6.1-Sol を上回った」は、この77図の点推定の差であって、区間の上では確定していない。
- 4.4(c) の合成図 vs 実論文の表は、`results/*plotqa-dot-line*.json`(合成図)と 4.1 の値に一致し、比(実論文 / 合成図)もすべて表のとおり。
