# 合成図と実論文の図での比較 — PlotQA dot_line 100(2026-10-05)

design §7.75 (B)。同じモデル・同じ採点(点単位の F1、τ = 軸レンジの 2%)で、マーカー形式の既存の合成図
(PlotQA test の dot_line 100図、CC-BY-4.0、`data/synthetic/plotqa_dot_line/`)と実論文の図97図を比べた。

- 合成図: x は年(目盛ラベルが数値)、マーカーは6種類からランダム、1〜4系列、線形軸のみ。正解は生成元の値(誤差なし)。
  軸レンジは目盛の最初と最後の値。評価項目の作成は `scripts/eval/synthetic_plotqa.py`。
- 合成図で学習したモデルは軸レンジを受け取れないので、どちらのデータでも「軸レンジなし」。汎用 VLM の行も「軸レンジなし」で比べる。
- 実行: RTX 4090。合成図で学習したモデルは実論文の図と同じ worker・同じ設定(DePlot はパッチ上限 4,096)。
  Qwen3.5-9B は vLLM の bf16、実論文の図と同じ v3 単発プロンプト。

Qwen3.5-9B の軸レンジありは合成図 0.962 / 実論文 0.470。

## 読み取り

1. **この環境は機能している.** TinyChart と DePlot は論文の値を著者の採点コードで再現した
   (`2026-10-05-repro-published-scores.md`)。
2. **マーカー形式の合成図なら読める.** ChartGemma を除く5モデルが 0.88〜0.96。汎用 VLM とチャート専用モデルに差はない。
3. **実論文の実験グラフでは大きく落ちる.** 同じ指標で 0.04〜0.49。チャート専用モデルは合成図の 5〜30% まで落ち、
   汎用 VLM(半分)より落ち方が大きい。合成図への適応が強く、実論文の図(多系列・密なマーカー・論文ごとに異なる体裁)
   に一般化しない。
4. ChartGemma は合成図でも 0.50 と低く、表を出さずに説明文を返す図がある(15/100 が表として読めない)。表抽出の
   公式プロンプトが無く、こちらで用意したプロンプトを使っている点が影響している可能性がある。

## 限界
