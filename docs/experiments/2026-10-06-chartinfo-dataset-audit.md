## 理由 — 注釈は段階的に進む設計

XML 側の検証フラグが、各図がどの段階まで進んだかを記録している。

| チャート種別 | 01_CLASS | 01_PANELS | 02_TEXT | 03_LEGEND | 04_AXIS | **05_DATA** |
|---|---|---|---|---|---|---|
| line (10,556) | 10,556 | 10,556 | 2,236 | 1,947 | 1,920 | **1,530** |
| vertical_bar (5,454) | 5,454 | 5,454 | 1,899 | 1,659 | 1,635 | **1,343** |
| **scatter-line (1,818)** | 1,818 | 1,818 | 67 | 66 | 65 | **7** |
| scatter (1,350) | 1,350 | 1,350 | 932 | 897 | 870 | **558** |
| horizontal_bar (787) | 787 | 787 | 731 | 622 | 610 | **504** |
| vertical_box (763) | 763 | 763 | 602 | 521 | 519 | **462** |
| map / pie / heatmap / manhattan / area / surface / venn / interval系 | 全数 | 全数 | 0〜3 | 0〜3 | 0〜3 | **0** |

全図が分類とパネル分割は通っているが、そこから先が急激に減る。

原典に書かれている理由は次のとおり(ICPR 2020 competition paper、Davila et al.)。

1. **収集と注釈が別工程である。** 画像の収集は CNN の埋め込み空間からのサンプリングで自動化され、
   「6万5千枚超を収集し、うち2万2千枚超が単一パネルのチャート」まで一気に拡大した。
   深い注釈はこの規模に追いついていない。
2. **データ注釈の対象は Line / Scatter / Box / Bar に限られる。** 原典:
   「最後に、特定の種類のチャート(Line、Scatter、Horizontal/Vertical Box、Horizontal/Vertical Bar)
   についてデータを注釈した」。map / pie / heatmap などは対象外で、0件なのは設計どおりである。
3. **競技会がタスクごとに異なる分割を使っていた。** テストセットは5つの互いに素な分割に分けられ、
   Task 6a/6b に割り当てられたのは UB-PMC で 726図だけだった。全図に全タスクの正解を用意する
   必要がそもそもなかった。

後継の **CHART-Info 2024**(ICPR 2024)は、この設計を変えている。オフラインのベンチマークに移行して
互いに素な分割をやめ、「各図で利用可能な正解に基づく」4つの重複を許す分割(DS1〜DS4)を定義した。
データ抽出(Task 6/7)に使える DS4 は訓練 5,427図 / 評価 2,676図である。注釈も最初の2段階を
半自動化し(認識器が初期ラベルを生成、注釈者が検証・修正)、「前年までと比べて注釈時間を半減させた」と
述べている。

## 入っているデータの中身

値がある図については、注釈は実データである。例(PMC1090595、line):

```
系列 '< 50 years'   9点: {x: 0.058, y: 9.021}, {x: 2.865, y: 7.381}, ...
系列 '50-65 years'  9点: {x: 0.125, y: 8.473}, {x: 3.099, y: 7.340}, ...
```

軸の値空間に変換済みの (x, y) で、系列名(凡例テキスト)つき。ピクセル座標
(`task6.output.visual elements`)と目盛位置(`task4.output.axes`)も別に保持されているので、
ピクセルからの再校正もできる。

## 本研究にとっての含意

- **使えるのは x が数値の 1,748図**(line 1,256 / scatter 492)。棒・箱は x がカテゴリで対象外
- 分野は PubMed Central なので**生物医学**。材料科学(熱電・電池・磁性)は実質的に含まれない
- 1.2 で引く「実図での先行評価」としては妥当。ただし「注釈が全図に揃っている」という前提で
  引用してはいけない

# 追記2: scatter-line がゼロな理由、およびデータ抽出タスクの実施状況

## scatter-line は「対象外」であって「挫折」ではない

CHART-Info 2024 の原文(Task 6 の節):

> our dataset provides data annotations for: horizontal/vertical bar charts, vertical box plots,
> scatter plots and line charts.
> (我々のデータセットは、横/縦棒グラフ、縦箱ひげ図、散布図、折れ線グラフについてデータ注釈を提供する)

ICPR 2020 の記述も同じ4種(Line、Scatter、Box、Bar)である。**scatter-line はどちらの列挙にも
入っていない。** データ注釈の対象型として一度も定義されていないので、ゼロは実装どおりである。

ただし**なぜ対象外にしたかの理由は、どちらの論文にも書かれていない。** scatter-line は点と線が
両方描かれるため、「点を取るのか線を取るのか」を決める必要がある。他の4種にはこの曖昧さがない。
本研究が issue #529(線形図サブセット)で直面しているのと同じ問題である。

## データがなくても競技会で使えた理由 — タスクが階層構造だから

7タスクはピラミッド型で、下のタスクほど多くの図を使う(ICPR 2024 訓練セット)。

| タスク | 必要な注釈 | 図数 |
|---|---|---|
| Task 1 分類 | チャート型のラベルのみ | 36,182 |
| Task 2 テキスト検出 | + テキスト領域 | 8,343 |
| Task 3-5 役割分類・軸・凡例 | + 軸と凡例 | 6,965〜7,065 |
| **Task 6-7 データ抽出** | **+ データ点** | **5,427** |

**scatter-line 3,446図は Task 1(分類)で使われている。** しかも分類タスクの主役である。
2024年の論文は、分類が難しい例として scatter-line を名指ししている:

> 画像を縮小すると、line と scatter-line のような難しい対を見分ける細部が失われうる
> 人間の注釈者にとっても分類が難しい画像がある。図2.b の scatter-line は line chart と容易に混同されうる

## scatter のデータ注釈は実在し、中身も揃っている

実例(ICPR 2024 訓練セット、`PMC1183521___pgen.0010002.g003.json`):

```
系列 'Expression down'    10点  {x: -1.683, y: 2.066}, {x: -1.508, y: 2.569}, ...
系列 'On Chromosome IV'    8点  {x: -1.591, y: 6.291}, {x: -1.879, y: 3.513}, ...
系列 'unc-43 CaMKII'       7点  ...
x目盛 7本, y目盛 7本
```

系列名(凡例テキスト)、軸の値空間に変換済みの点列、目盛位置がすべて揃っている。
2024年版で x が数値の scatter は **592図**(2022年版は 492図)。

## データ抽出タスクは、実際にはほとんど測られていない

| 版 | Task 6b(データ抽出)の実施状況 |
|---|---|
| ICPR 2020 | 2チーム提出。実図の全体 data-score 0.552 / 0.765。**scatter は 0.232 / 0.710** |
| ICPR 2022 | **1チームのみ、しかも縦箱ひげ図のみの提出**(IIIT_CVIT_Chart_Understanding、総合 0.085)。scatter / line の結果なし |
| CHART-Info 2024 | **ベースラインなし。** 論文: 「各チャート型についてベースラインを提供することは本研究の範囲外である」 |

つまり**実図の scatter / line のデータ抽出スコアとして公開されているのは、ICPR 2020 の2チームだけ**である。
2022年は提出が集まらず、2024年はベースライン自体が用意されていない。

学習済みモデルも公開されていない(GitHub kdavila/CHART_Info_2024: 「近日公開予定。至急必要な場合は連絡を」)。
ICPR 2020 の参加チームのシステムも非公開である。

# 追記3: CHART-Infographics の使える図の 43% は材料科学である

「PubMed Central だから生物医学」という想定は誤りだった。データ値があり x が数値の 2,214図を
ファイル名の誌名で分類した結果:

| 種別 | 使える図 | うち材料科学系 | 割合 |
|---|---|---|---|
| scatter | 592 | 257 | 43.4% |
| line | 1,622 | 701 | 43.2% |
| **合計** | **2,214** | **958** | **43.3%** |

誌名の内訳(上位):

| 図数 | 誌 | 分野 |
|---|---|---|
| **832** | **materials**(MDPI) | **材料科学** |
| 183 | ijerph | 公衆衛生 |
| 139 | g(G3: Genes\|Genomes\|Genetics) | 遺伝学 |
| 136 | cmmm(Comput Math Methods Med) | 医用計算 |
| **126** | **nanomaterials**(MDPI) | **ナノ材料** |
| 87 | pgen(PLOS Genetics) | 遺伝学 |

MDPI の *Materials* と *Nanomaterials* が PMC に収録されているため、**単一誌としては Materials が最大**
(全体の 38%)になる。PMC は「生物医学アーカイブ」だが、オープンアクセスの材料科学誌を含む。

本研究のパイロット(scatter 10図を系列数と点数で層化抽出)でも、10図中6図が materials /
nanomaterials 由来だった。無作為ではなく決定的な抽出なので、偶然ではない。

## 含意

- 「生物医学 vs 材料科学」という分野差の主張は、**二重に成り立たない**。チャート型の分布でも
  (追記2)、収録誌でも成り立たない
- CHART-Infographics の scatter/line サブセットは、**材料科学のベンチマークとして部分的に使える**。
  958図が材料科学系で、本研究の94図より一桁多い
- ただし正解データの出所は異なる(ベンチマークのための注釈 vs Starrydata の専門家デジタイズ)。
  比較するときはこの差を明示する必要がある
