# 1. 序論

## 1.1 このベンチマークは何か

real-chart-bench は、**公開論文に実際に印刷された図**から数値データを読み取る能力を測るオープンベンチマークである。100図・379曲線・8,471点、32本の論文、すべて CC BY。

既存のチャート抽出評価 — LineEX (WACV 2023) は合成データ43万枚で学習・評価し、ChartOCR や LineFormer も評価の中心は合成図である。合成図には、軸が常に読め、系列が常に分離でき、単位が常に一貫しているという性質がある。実際の論文の図にはそのどれもない。

正解データは Starrydata の人手デジタイズ済み XY データを用いる。これは**このベンチマークのために作られたものではない**。熱電材料の研究者が自分たちの研究のために、10年以上かけて論文の図から起こしてきた実データである。

## 1.2 自分で作っていない正解データを使うということ

自作の正解データには、作った側の癖がそのまま入る。どの図を選ぶか、どこまで読むか、曖昧な点をどう扱うか。それらは無意識のうちに「測りたいもの」に寄る。

外部の正解データを使うと、その癖は消える代わりに**別の問題が全部出てくる**。図とデータの対応が取れているか。単位系が一致しているか。図に5系列あるのにデータが4曲線しかないとき、それは抽出手法の失敗なのか正解データの不足なのか。

本論文の構築手法(2章)の大半は、この問いに答えるための機構である。157件の候補から出発して採点可能な100図に至る過程で、**57件が脱落した**。その内訳と判定根拠を公開することが、データセットそのものと同じくらい重要な成果だと考えている。

## 1.3 貢献

1. **実論文図による公開ベンチマーク** — 100図、CC BY のみ、正解データ込みで再配布可能
2. **構築手法** — ライセンス判定、図とデータのペアリング、その検証、除外の分類体系
3. **測定** — 言語モデル(2世代・計7種)、専用モデル LineFormer、CVベースライン2種、軸校正の有無2条件
4. **方法論上の知見** — 正解データを見ながら候補を選ぶと測定対象を最適化してしまうこと、および盲検測定でそれを避ける手順
