# 1. 序論

## 1.1 このベンチマークは何か

real-chart-bench は、**公開論文に実際に印刷された図**から数値データを読み取る能力を測るオープンベンチマークである。97図・376曲線・8,317点、30本の論文、すべて CC BY。すべての図にマーカー(測定点)が描かれている。

評価は点単位で行う。抽出手法が、図に描かれた実験点(マーカー)を、正しい系列として、軸レンジの2%以内で見つけたかを F1 で測る(3章)。

正解データは Starrydata の人手デジタイズ済み XY データを用いる。これは**このベンチマークのために作られたものではない**。熱電材料の研究者が自分たちの研究のために、10年以上かけて論文の図から起こしてきた実データである。

## 1.2 先行研究

チャート抽出の評価の多くは合成図で行われてきた。LineEX(WACV 2023)は合成データ43万枚で学習・評価し、ChartOCR や LineFormer も評価の中心は合成図である。散布図の点抽出を扱った Scatteract(ECML-PKDD 2017)も合成図で評価しており、学習済みの重みは公開されていない。DePlot などの、合成図で学習したチャート専用モデルも同様である。合成図には、軸が常に読め、系列が常に分離でき、単位が常に一貫しているという性質がある。実際の論文の図にはそのどれもない。

ただし、実図による評価は本研究が初めてではない。CHART-Infographics(ICPR 2020 以降)は PubMed Central の CC-BY / CC-0 論文から集めた実図(散布図を含む)を人手で注釈して評価に使っている。PlotExtract(Polak & Morgan, 2025)は、出版済み論文の図44枚でも評価している。評価方法の比較は 3.5 にまとめた。

本研究の差分は次の4点である。

1. **材料科学の実験図に特化する。** 対象は熱電材料の温度依存性プロットなど、マーカーで実験点を示す図である
2. **正解データを、独立した専門家のデジタイズ DB との対応づけで得る。** ベンチマークのために注釈したものではなく、Starrydata が研究目的で起こしてきたデータを、図と数値的に照合して使う(2章)
3. **再配布できる図だけで構成する。** すべて CC BY で、正解データとともに公開する
4. **クラウドの言語モデル、ローカルで動く汎用 VLM、専用モデル、CV を同じ条件で横断して測り、配備の制約(データを外に出せない場面)を論じる**(4章、6章)

## 1.3 自分で作っていない正解データを使うということ

自作の正解データには、作った側の癖がそのまま入る。どの図を選ぶか、どこまで読むか、曖昧な点をどう扱うか。それらは無意識のうちに「測りたいもの」に寄る。

外部の正解データを使うと、その癖は消える代わりに**別の問題が全部出てくる**。図とデータの対応が取れているか。単位系が一致しているか。図に5系列あるのにデータが4曲線しかないとき、それは抽出手法の失敗なのか正解データの不足なのか。マーカーが重なるほど密な図で、人がすべてのマーカーを取っていないとき、取っていない点を出した手法は誤りなのか。

本論文の構築手法(2章)と評価系(3章)の大半は、この問いに答えるための機構である。157件の候補から出発して採点可能な97図に至る過程で、**60件が脱落した**。その内訳と判定根拠を公開することが、データセットそのものと同じくらい重要な成果だと考えている。

## 1.4 貢献

1. **実論文図による公開ベンチマーク** — 97図、CC BY のみ、正解データ込みで再配布可能
2. **構築手法** — ライセンス判定、図とデータのペアリング、その検証、除外の分類体系
3. **評価系** — マーカーの位置を点単位で測る主指標、マーカーが密な図の分離、人のデジタイズ精度に照らした τ の位置づけ
4. **測定** — クラウドの言語モデル(2世代・計7種)、ローカル VLM 3種、専用モデル LineFormer、CV ベースライン2種、軸校正の有無2条件
5. **方法論上の知見** — 正解データを見ながら候補を選ぶと測定対象を最適化してしまうこと、および盲検測定でそれを避ける手順
