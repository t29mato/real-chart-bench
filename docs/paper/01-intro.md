# 1. 序論

## 1.1 このベンチマークは何か

real-chart-bench は、**公開論文に実際に印刷された図**から数値データを読み取る能力を測るオープンベンチマークである。91図・354曲線・7,061点、29本の論文、すべて CC BY。すべての図にマーカー(測定点)が描かれている。

評価は点単位で行う。抽出手法が、図に描かれた実験点(マーカー)を、正しい系列として、軸レンジの2%以内で見つけたかを F1 で測る(3章)。

正解データは Starrydata の人手デジタイズ済み XY データを用いる。これは**このベンチマークのために作られたものではない**。Starrydata チームのデータ収集者が、マテリアルインフォマティクスのために 10年以上かけて論文の図から起こしてきた実データである。

## 1.2 先行研究

チャート抽出の評価の多くは合成図で行われてきた。LineEX(WACV 2023)は合成データ43万枚で学習・評価し、ChartOCR や LineFormer も評価の中心は合成図である。散布図の点抽出を扱った Scatteract(ECML-PKDD 2017)も合成図で評価しており、学習済みの重みは公開されていない。DePlot などの、合成図で学習したチャート専用モデルも同様である。本研究で測ると、これらのモデルは合成図では高い値を出すが、実論文の図ではほとんど読めない(4.4)。合成図には、軸が常に読め、系列が常に分離でき、単位が常に一貫しているという性質がある。実際の論文の図にはそのどれもない。

ただし、実図による評価は本研究が初めてではない。**CHART-Infographics**(University at Buffalo + Adobe Research、ICDAR 2019 / ICPR 2020 / ICPR 2022)は PubMed Central の CC-BY 論文から集めた実図を人手で注釈して評価に使っており、**実図と合成図の落差も本研究より先に観測している**。ICPR 2020 の Task 6b(上流タスクの正解を与えたデータ抽出)では、同じ2チームが合成図(Adobe Synth)と実図(UB-PMC)で次の差を出した。

| | 合成図 | 実図 |
|---|---|---|
| Line | 0.926 / 0.987 | 0.679 / 0.698 |
| Scatter | 0.419 / 0.867 | 0.232 / 0.710 † |
| 全体の data-score | 0.703 / 0.962 | 0.552 / 0.765 |

† 実図 scatter の 0.232 / 0.710 が何の値かは、手元の資料で確定できていない。本研究のデータセット監査(`docs/experiments/2026-10-06-chartinfo-dataset-audit.md`)はこれを scatter の data-score として写したが、採点スクリプトの注記(`scripts/eval/score_chartinfo_pilot.py`)は全チャート型の平均としている。原論文で確認するまで(`docs/experiments/TODO-literature.md` の7)、4.8 では「全チャート型(原論文で要確認)」として扱う。

同論文は「合成データでの結果は時に完璧に近いが、同じモデルが実図からのデータ抽出となると改善の余地が残る」と結論している。本研究の 4.4 は、この観測が **2020年の畳み込みモデルから 2026年の言語モデル・チャート専用モデルに至っても再現すること**を、点単位の指標で示したものである。

PlotExtract(Polak & Morgan, 2025)は、出版済み論文の図44枚でも評価している。評価方法の比較は 3.5 にまとめた。

**実図のベンチマークは、2025〜2026年に急に増えた。** 本研究の設計を固めた後に現れたものを含め、現時点で次のものがある(2026-10-07 調査)。

| ベンチマーク | 規模 | 出所 | 指標 |
|---|---|---|---|
| **PaperUnPlot**(TaDA 2026) | 実図 950 対、10 種(+ 合成の対照) | PubMed Central + arXiv | NMS(軸レンジ正規化) |
| **EpiCurveBench**(2026) | 実図 1,000 枚(折れ線 71.4%) | 公衆衛生機関の公開資料 | ECS(y 軸レンジ正規化、DP 整列) |
| **ExChart-Bench**(ACM 2026) | 実図 744 + 合成 2,856 | ChartQAPro、CharXiv、web | Adaptive MAPE |
| **MetalThermoChartIE / PolyCompChartIE** | 未確認 | 材料科学論文 | RCLS |
| **CHART-Info 2024** | 実図 51,275 枚。ただし**データ点があるのは 8,103 枚(15.8%)** | PubMed Central | Task 6/7 指標 |
| **本研究** | 実図 91 枚 | 熱電材料の CC BY 論文 | 点 F1(軸レンジ正規化) |

**どれも「実図では合成図より成績が落ちる」という同じ結論に達している。** PaperUnPlot は 35.6 万枚のチャート分布を調べ、既存ベンチマークが実際の論文の図を体系的に取りこぼしていることを示している。したがって **4.4 の観測は本研究に固有の発見ではない**。本研究が加えるのは次の3点に絞られる。

1. **測るのがマーカーの位置そのものであること。** 上記はいずれも表への変換(chart-to-table)か系列の形の一致を測る。本研究は「どの実験点を取れたか」を点単位で数える(3.2)
2. **正解データが独立の専門家 DB 由来であること。** 上記はいずれもベンチマークのために注釈している。本研究の正解は、材料情報学のために10年以上かけて作られた Starrydata のデジタイズである(1.3)
3. **図ごと再配布できること。** すべて CC BY で、図と正解データを一緒に公開する

規模では明確に負けている(91 対 950 / 1,000 / 8,103)。この位置づけは 7.13 に書いた。

ただし **CHART-Info 2024 の規模は、データ抽出に使える図で数えると 51,275 枚ではなく 8,103 枚である**(論文 Table 3、2026-10-08 に原論文で確認)。残りは分類や文字検出までの注釈しかない。同論文は「**タスク6と7のベースラインは本稿の範囲外**」とも明記しており、**データ抽出そのものには公表ベースラインが無い**。

本研究の差分は次の5点である。

1. **材料科学の実験図に特化する。** 対象は熱電材料の温度依存性プロットなど、マーカーで実験点を示す図である
2. **正解データを、独立した専門家のデジタイズ DB との対応づけで得る。** ベンチマークのために注釈したものではなく、Starrydata が研究目的で起こしてきたデータを、図と数値的に照合して使う(2章)
3. **再配布できる図だけで構成する。** すべて CC BY で、正解データとともに公開する
4. **クラウドの言語モデル(Claude、GPT)、ローカルで動く汎用 VLM、学習済みの専用モデルを同じ条件で横断して測り、配備の制約(データを外に出せない場面)を論じる**(4章、6章)
5. **出所の違う2つの正解データで同じ測定を行う。** 本研究の正解データは Starrydata 由来である。測定結果がその注釈過程に固有でないことを示すには、別の作られ方をした正解で同じモデルを測る必要がある。CHART-Infographics(UB-PMC)は、ベンチマークのために雇われた注釈者が図を見て作った正解であり、Starrydata(材料情報学のためのデジタイズ DB)とは目的も過程も違う。彼らの scatter 582図すべてを同じ4モデルで測ると、点 F1 は本研究の77図の 0.95〜0.99 に対して 0.85〜0.89 だった。失点のかなりの部分は読み取りの誤りではなく、正解データの書き方の規約(点ごとのラベルを別系列にする、%目盛を割合で持つ)と2本目の y 軸、採点方式による(4.8.2)。そうした特徴のない図では Opus 5.5 が 0.937 である

## 1.3 自分で作っていない正解データを使うということ

自作の正解データには、作った側の癖がそのまま入る。どの図を選ぶか、どこまで読むか、曖昧な点をどう扱うか。それらは無意識のうちに「測りたいもの」に寄る。

外部の正解データを使うと、その癖は消える代わりに**別の問題が全部出てくる**。図とデータの対応が取れているか。単位系が一致しているか。図に5系列あるのにデータが4曲線しかないとき、それは抽出手法の失敗なのか正解データの不足なのか。マーカーが重なるほど密な図で、人がすべてのマーカーを取っていないとき、取っていない点を出した手法は誤りなのか。

本論文の構築手法(2章)と評価系(3章)の大半は、この問いに答えるための機構である。157件の候補から出発して採点可能な91図に至る過程で、**66件が脱落した**。その内訳と判定根拠を公開することが、データセットそのものと同じくらい重要な成果だと考えている。

## 1.4 貢献

1. **実論文図による公開ベンチマーク** — 91図、CC BY のみ、正解データ込みで再配布可能
2. **構築手法** — ライセンス判定、図とデータのペアリング、その検証、除外の分類体系
3. **評価系** — マーカーの位置を点単位で測る主指標、マーカーが密な図の分離、人のデジタイズ精度に照らした τ の位置づけ
4. **測定** — クラウドの言語モデル(Claude 2世代・計7種、GPT-6.1-Sol、GPT-5.5)、ローカル VLM 3種とその量子化、ローカルのエージェント(Codex CLI + Qwen3.8-27B)、合成図で学習したチャート専用モデル5種、専用モデル LineFormer。条件は2つ — 完全自動(軸の情報なし)と、人が軸を校正(目盛2本ずつのピクセル位置と値)。実行時間とトークン量も記録した
5. **合成図と実論文の図の比較** — 論文の値を再現できたチャート専用モデルが、マーカー形式の合成図では点 F1 0.88〜0.96 を出し、実論文の図では 0.04〜0.29 に落ちる。合成図で同程度の Claude は実論文の図でも落ちない(4.4)
6. **方法論上の知見** — 正解データを見ながら候補を選ぶと測定対象を最適化してしまうこと、および盲検測定でそれを避ける手順
