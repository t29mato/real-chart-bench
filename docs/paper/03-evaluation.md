# 3. 評価系

## 3.1 タスクの定義

抽出手法には以下を与える。

- 図の画像(PNG)
- x軸・y軸の範囲、およびそれぞれのスケール(linear / log)

求めるのは、図に描かれた各データ系列の点列 (x, y) を**図自身の軸単位で**返すことである。系列数は与えない。

軸範囲を与えるのは、**軸読み取りと系列抽出を分離する**ためである。両方を一度に測ると、スコアが下がったとき原因が特定できない。

軸を与えない条件(4.3)では、範囲もスケールも渡さず、**軸ごとの報告規則**だけを渡す。規則は3種類である。

- 印字された目盛と同じ数値で答える(軸タイトルの ×10⁴ などは掛けない)— 100図中85図の両軸
- 目盛が log10 値で印字されている軸は 10^値で答える — y軸13本
- °C で印字されているが正解が K の軸は K で答える — x軸2本

規則は、人手レビュー済みの印字目盛と正解の保存範囲を突き合わせて決めた。単位の慣習で失点させないためであり、軸表記の解釈そのものは測っていない。

## 3.2 主指標 — 実験点を見つけたか

材料科学の図に描かれた線の多くは近似線・ガイド線であり、価値があるのは「どの条件で実験し、どの値が出たか」、つまり**マーカーの位置**である。人がデジタイズするときも、必ずマーカーだけを抽出する。正解データ(Starrydata)の点はマーカーの位置であり、評価もそれに合わせて**点単位**で行う。データセットはマーカーのある図だけで構成する(線だけの図3枚は除外した。うち1枚は、元論文の本文から測定点ではなく計算値を滑らかに描いた線と判断した)。

**定義.**

1. **正規化.** 両軸を、その図の軸レンジで 0〜1 に写す。対数軸は log10 してから写す。人がプロット上でクリックするときの誤差に対応する量にするため、系列自身の値幅ではなく**軸レンジ**で割る。
2. **点の対応づけ.** 予測系列と正解系列の組ごとに、予測点 × 正解点の距離行列でハンガリアン法の**1対1**割り当てを行い、距離が τ 以下の組を「一致」とする。1対1にするのは、密に点を並べた線が1本で全正解点を取ったり、1つの予測点が複数の正解点を兼ねたりするのを防ぐためである。
3. **系列の対応づけ.** 系列の組のコストを `1 − F1_τ` としてハンガリアン法で割り当てる。割り当てられなかった正解系列の点はすべて見逃し、余った予測系列の点はすべて余計な点として数える。
4. **図ごとの値.** 再現率 = 一致点 / 正解点(実験点を見つけた割合)、適合率 = 一致点 / 予測点(余計な点を出さなかった割合)、その調和平均 F1、および一致点の平均距離(位置誤差)。
5. **τ.** 主値は軸レンジの 2%(Scatteract と同じ水準、3.3)。1% と 5% も併記する。
6. **集約.** 図ごとの値の平均を主とし、全点をまとめた値を併記する。

リーダーボードの並び順は **F1** とする。再現率だけを主にすると、線を画素の列として密に出す手法が、実験点を特定しないまま高得点になる。適合率は、近似線や参照線を系列として出した予測も減点する。

## 3.3 検討した評価方法

主指標を決めるまでに、以下の評価方法を検討した。

| 方式 | 先行例 | 何を測るか | 本研究での扱い |
|---|---|---|---|
| **曲線距離**: 予測を正解の x 位置に線形補間し、y の差を正規化して平均。系列はハンガリアン法で対応づけ | ChartOCR、LineFormer(折れ線)。CHART-Infographics の折れ線も補間による差の積分 | 予測曲線が正解点の近くを通るか | v0 の主指標。**参考指標として残す**(3.4)。x をこちらが与えるため、近似線をなぞった予測や、x を目盛の値に丸めた予測でも点が出る。系列の本数が合うだけで総合スコアが約 0.67 入り、読み取り精度の差を隠す |
| **しきい値つき点一致**: 各軸の誤差が値幅の 2% 以内なら一致。近い順に1対1で確定し、図ごとに適合率・再現率・F1 | Scatteract(Cliche et al., ECML-PKDD 2017)。F1 > 0.8 を「抽出成功」と定義 | 実験点を見つけたか | **採用**(主指標の骨格)。対応づけを近い順からハンガリアン法に、正規化を正解の値幅から軸レンジに変えた |
| **しきい値なしの割り当てコスト**: 距離を上限1で打ち切ったコスト行列をハンガリアン法で解き、`1 − 総コスト / max(予測数, 正解数)`。点の距離は正解点の共分散で正規化(マハラノビス距離)。系列名の編集距離も加味 | CHART-Infographics(ICPR 2020 以降の Task 6b / 7) | 点の検出と位置の精度を1つの連続値で | 不採用(将来の補助指標候補)。しきい値の恣意性はないが、「見つけた / 見逃した」が1つの数に混ざり、材料科学の利用者に読みにくい。系列名は、このコーパスでは1図内で区別できない(3.4) |
| **しきい値なしの最近傍一致**: 正規化空間で最も近い組から順に一致とし、適合率・再現率と x / y の平均絶対誤差 | PlotExtract(Polak & Morgan, 2025)。出版済み論文の図44枚でも評価 | 点の数の過不足と位置誤差 | 不採用。しきい値がないため、どれだけ離れていても一致として数えられる |
| **緩い正答率**: 特定の値が 5% 以内なら正解 | ChartQA | 質問応答としての数値の正しさ | 不採用。曲線や点の集合全体を評価しない |

## 3.4 参考指標 — 曲線距離(v0 の主指標)

LineFormer / ChartOCR 系の「正規化y差分 + 二部マッチング」を基礎とし、2段階で構成する。

### 第1段: 系列と系列の対応づけ

予測N本 × 正解M本のコスト行列を作り、`scipy.optimize.linear_sum_assignment`(Kuhn-Munkres、ハンガリアン法)で**全体の合計コストが最小になる割り当て**を求める。

貪欲法(近いものから順に確定)ではない点が重要である。貪欲法は局所的に良い対応を先に確定してしまい、全体として悪い割り当てを生む。予測Aが正解1にやや近く、予測Bが正解1に非常に近いが他とは全く合わない場合、貪欲法はA→正解1を取ってBを不適切なペアに押し込む。ハンガリアン法はこれを避ける。

余った正解曲線は**検出漏れ**、余った予測曲線は**誤検出**として明示的に報告する。これが `match_rate` を構成する。図の系列数を誤った手法が「スコア0」に潰れるのではなく、何が起きたかが読めるようにするためである。

**系列ラベルは対応づけに使っていない。** 対応は純粋に幾何的である。このコーパスでは `prop_y` が1図内の全曲線で同一の文字列であり(例: 9曲線すべて "Seebeck coefficient")、使えたとしても区別できない。

### 第2段: ペア内の点の対応づけ

最近傍ではない。**x座標で揃える**。

```
pred_y_interp = numpy.interp(gt_x, pred_x, pred_y)
span          = max(gt_y.max() - gt_y.min(), 0.05 * |y_range|)   # 線形 y 軸のとき
point_errors  = |pred_y_interp - gt_y| / span
```

正解データのx位置に予測を線形補間し、yの差のみを測る。x軸が対数なら log10(x) 空間で補間する。

この設計により、**予測は正解と同じx刻みでサンプリングする必要がない**。同じx範囲をカバーしていれば点数が違ってよい。抽出手法に「10〜20点で十分」と指示できるのはこのためである。

正解データ自身のyレンジで割るため、予測と正解が共有する単位係数は打ち消される。2.6の移行がスコアを動かさなかったのはこの性質による。

**正規化の幅には下限を置く**(軸レンジの5%)。系列自身の幅だけで割ると、ほぼ平らな系列が拡大鏡になる。18869-18874 の x=0 系列は 0〜40 の軸上で幅 0.41 しかなく、0.26 の読み誤差が距離 0.64 と評価されていた。下限は軸の幅に比例するので単位係数の相殺は保たれる。対数 y 軸には下限を置かない。幅が下限を超える大多数の系列では何も変わらず、主表の全行で変化は +0.0013 以下だった。

### 総合スコア

`summary_score` は match_rate、平均曲線距離、平均カバレッジ比の合成である。x範囲が重ならない場合は `coverage_ratio = 0` として最悪値を与える。

補助指標として双方向最近傍距離(Chamfer距離)も算出するが、**総合スコアには寄与しない**。

## 3.5 境界条件

点単位(主指標):

- 予測が空 → 再現率 0。正解が空の図はデータセットにない
- 距離がちょうど τ → 一致に含める
- 対数軸で値が 0 以下の予測点 → 一致しない点として適合率の分母にだけ入る
- 軸レンジの外の点 → そのまま距離を計算する

曲線距離(参考指標):

- 予測が空 → 全正解が検出漏れ
- 正解が空 → 全予測が誤検出
- 正解が平坦(y方向に幅がない)→ 線形軸では下限の幅で割る。下限のない対数軸では、スケール相対の厳密一致判定に切り替える

## 3.6 比較可能性

全手法に同一の情報を与える。言語モデルにも LineFormer にも CV ベースラインにも、`ExtractionTask` が運ぶのは画像と軸範囲だけである。採点時の軸範囲は常にレジストリの現行値を使う。モデルに見せた範囲を使うと、単位移行前に作ったタスクでは正規化の下限が旧単位で計算されてしまう(実際に1図で起き、結果閲覧ページの独立な再採点で見つかった)。

ベースラインの公表値には**合成図を含めない**。ハーネスの自己テスト用に合成図3枚を用意しているが、これを平均に混ぜると「合成図ではなく実図で測る」という前提に反する公表値になる。自己テストの結果は `n_synthetic_fixtures` / `mean_synthetic_score` として別掲し、`per_figure` には残して監査可能にする。
