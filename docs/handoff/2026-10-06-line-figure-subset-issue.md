# 線形図(マーカーなし)のサブセットを作る — 先行研究と比較できるようにする

## なぜ必要か

現在のデータセットは **マーカーのある図だけ**(94図)で構成している。主指標を点単位の F1 にしたとき、「人がデジタイズするのはマーカーだけ」という前提に合わせ、線だけの図3枚を `no_markers` で除外した(design §7.77、論文 2.3)。

この判断は点単位の評価には正しいが、**先行研究と比較できなくなる**という副作用がある。

- **LineFormer / LineEX / ChartOCR は折れ線のモデルである。** LineFormer を現行データで測ると点 F1 0.033(再現率 0.863、適合率 0.018)で、これは「線を画素の列として出し、マーカーを1点として特定しない」ことの反映であって、**線を引く能力の評価にはなっていない**(論文 6.3)。
- さらに LineFormer は、点を結ぶ線のない散布図では検出候補の信頼度が 0.000〜0.048 にとどまり**何も返さない**。現在のデータセットは全94図がマーカーの図なので、LineFormer にとっては想定外の入力ばかりである。
- 線形図のサブセットがあれば、LineFormer / LineEX / ChartOCR を**それらが想定する入力**で測れる。曲線距離(`summary_score`)での比較になり、過去研究の土俵に乗れる。

論文 7.11 の「今後の課題」にも、線だけの図を評価に戻すことを挙げている。

## 探すもの

**Starrydata に収録されていて、かつ著作権上問題のない(CC BY 等で再配布可能な)論文の、線形図。**

オーナーの見立て(2026-10-06):

> 電池材料の充放電曲線や、磁性材料のバタフライプロットが結構データあるはずなので使うと良い気がする。これらは密度が高いので、線形のグラフになっているはずなので。

- **充放電曲線**(電池材料) — 電圧 vs 容量。測定点が密なので連続線として描かれる
- **バタフライプロット / ヒステリシスループ**(磁性材料) — M-H 曲線。同じく密で、往復するため x が単調でない

いずれも**マーカーを打たず連続線で描く**のが通例で、現在のデータセットにない図の種類である。

## 作業

1. **Starrydata 側に該当データがあるか確認する。** 現在の94図の `prop_y` は熱電物性(Electrical conductivity、Seebeck coefficient、ZT、Thermal conductivity など)に集中している。充放電曲線・磁化曲線の物性名で収録があるかを調べる
2. **その論文群のライセンスを判定する。** 既存の `classify_license`(OpenAlex 一次索引 + Crossref 裏取り、CC-BY 系のみ)をそのまま使う(論文 2.1)
3. **図とデータのペアリング**を既存の手順で行い、`verified` にする(論文 2.2)
4. **別サブセットとして登録する。** 現在の主データセット(マーカーのみ)とは混ぜない。`dataset_version` を分ける(例: `v0-lines-nNN`)

## 評価設計で決める必要があること

線形図は点単位の指標が使えないので、**別の表になる**。論文 7.11 に書いたとおり:

> 線だけの図: 点単位の指標が前提とする「人はマーカーだけを取る」が成り立たない。線を何点で表すかの約束を決めたうえで、曲線距離など線に適した指標で別の表を立てる。

決めるべき点:

- 正解データの点列を「曲線上のサンプル」とみなす前提でよいか(現在の `summary_score` はそう扱っている)
- 予測に何点を求めるか。密な線を何点で表すかの約束がないと、適合率の意味が定まらない
- x が単調でない図(バタフライプロット)をどう扱うか。**現在の曲線距離は `numpy.interp` で x に沿って補間するので、x が往復する曲線はそのままでは扱えない**(論文 3.6)。ヒステリシスループを入れるなら、メトリクス側の拡張が要る

## 注意

- **x が単調でない図は、現在の評価系では採点できない。** バタフライプロットを入れるなら、曲線距離の実装を弧長パラメータ化などへ拡張する必要がある。充放電曲線は x(容量)が単調なので既存の実装で扱える。**充放電曲線から始めるのが安全**
- 現在 `no_markers` で除外した3図(22102-21245、22102-21246、4965-13164)は、このサブセットの最初の構成要素になりうる。ただし 4965-13164 は元論文の本文から「測定点ではなく計算値を滑らかに描いた線」と判断しており、実測データの図ではない(論文 2.3)
- マーカーのある図とない図を**1つのリーダーボードに混ぜない**。測っているものが違う
