# 散布図からのデータ抽出

`images/` にある10枚の図から、プロットされているデータ点を読み取ってください。
すべて公開論文に印刷された実際の散布図です。

## 出力

`predictions.json` を作り、次の形式で書いてください。

```json
{
  "fig_01.png": [
    {"name": "系列名", "data": [{"x": 1.0, "y": 2.0}, {"x": 3.0, "y": 4.0}]},
    {"name": "別の系列", "data": [{"x": 1.0, "y": 5.0}]}
  ],
  "fig_02.png": [...]
}
```

## 値の読み方

- 図に描かれたマーカー(測定点)をすべて拾い、1マーカー=1点としてマーカーの中心を読む。
  近似線・回帰直線・ガイド線・誤差棒の端は**出さない**
- 軸の範囲もスケールも与えません。目盛を自分で読んでください
- 値の書き方は次の規則に合わせてください(採点側の正解データの書き方です):
  - **目盛に「%」が付いている**(`25%`)ときは**割合**で書く: `25%` → `0.25`。
    目盛が数字だけで、「%」が軸タイトルにだけあるときは目盛の数字のまま(`25` → `25`)
  - **軸全体の倍率**(軸タイトルや軸の端にある `×10⁴`、`(x1000)` など)は**掛けない**。
    目盛の数字のまま書く
  - 目盛が `1E-5` のような E 表記のときや、対数軸の目盛が `10⁻³` のようなときは、
    その値そのものを書く(`1e-5`、`0.001`)。対数軸でも log を取らず値を書く
  - **数字の目盛がない軸**は、プロット領域の中の位置を 0〜1 で書く(左端・下端が 0、右端・上端が 1)
  - **右側に2本目の y 軸がある**ときは、どの系列も**左の y 軸の目盛**で読んで y を書く
    (右の軸に属する系列も、左の軸の単位に換算する)
  - 数字の間のカンマは、後ろが3桁ちょうどなら桁区切り(`1,000` = 1000、`350 000` = 350000)、
    それ以外は小数点(`0,3` = 0.3)。目盛に付いた単位は外す(`40.0m` → 40)
  - 目盛の間隔は等しいのに値が不規則なとき(0, 80, 250, 500 …)は、
    隣り合う2つの目盛の間を直線で補間する

## 系列名の書き方(重要 — 採点の25%を占めます)

**凡例がある場合**は、凡例に書かれた文字列をそのまま `name` に入れてください。
凡例がなく、線や点のまとまり全体を指すラベルが図中にある場合は、そのラベルの文字列をそのまま使います。

**名前がない系列**は、空文字列ではなく、次の形式ちょうどで書いてください:

```
[unnamed data series #0]
```

番号は、その図の出力リストの中での**位置**(0始まり、名前付きの系列も数える)です。
例: 1番目が凡例付き、2番目が名前なしなら `[unnamed data series #1]`。

**記号の表記規則**(採点側が文字列一致で比較するため、この書き方に合わせてください):

- ギリシャ文字・数式記号は LaTeX 風に書く。例: `\mu m`、`\zeta`、`\Omega`、`\lambda`
- 下付き・上付きは `_{..}`、`^{..}` で書く。例: `Y_{2}O_{3}`、`m^{2}`
- 度数記号など、それ以外の文字は図の印字どおりに書く
- 単位の前の空白は、図の印字どおりにする

## 守ってほしいこと

- 1図終わるごとに `predictions.json` を書き直す(途中で止まっても有効な JSON が残るように)
- このディレクトリの外を読んだり検索したりしない。正解データが同じマシンのどこかにあり、
  見てしまうと測定が無意味になります
- 読めない図があれば空リスト `[]` を書く。キーは必ず10個そろえる

Python と画像ライブラリは使って構いません。
