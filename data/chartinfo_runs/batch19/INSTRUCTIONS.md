# 散布図からのデータ抽出

`images/` にある30枚の図から、プロットされているデータ点を読み取ってください。
すべて公開論文に印刷された実際の散布図です。

## 出力

`predictions.json` を作り、次の形式で書いてください。

```json
{
  "fig_01.png": [
    {"name": "系列名", "data": [{"x": 1.0, "y": 2.0}, {"x": 3.0, "y": 4.0}]},
    {"name": "別の系列", "data": [{"x": 1.0, "y": 5.0}]}
  ],
  "fig_02.png": [...]
}
```

## 値の読み方

- `x`, `y` は**図に印字された目盛と同じ数値**(軸タイトルの ×10⁴ などは掛けない)
- 図に描かれたマーカー(測定点)をすべて拾う。近似線・回帰直線・ガイド線は**出さない**
- 軸の範囲もスケールも与えません。目盛を自分で読んでください

## 系列名の書き方(重要 — 採点の25%を占めます)

**凡例やラベルがある場合**は、そこに書かれた文字列をそのまま `name` に入れてください。

**凡例もラベルも無い場合**は、空文字列ではなく、次の形式ちょうどで書いてください:

```
[unnamed data series #0]
```

番号は0始まりで、系列ごとに 0, 1, 2… と振ります。1系列しかなければ `[unnamed data series #0]`
だけです。

**記号の表記規則**(採点側が文字列一致で比較するため、この書き方に合わせてください):

- 度数記号は `*C` と書く(`°C` ではない)。例: `400 *C`
- ギリシャ文字・数式記号は LaTeX 風に書く。例: `\mu m`、`\zeta`、`\Omega`、`\lambda`
- 凡例が複数行に分かれている場合は `\n` で区切る
- 単位の前の空白は、図の印字どおりにする

## 守ってほしいこと

- 1図終わるごとに `predictions.json` を書き直す(途中で止まっても有効な JSON が残るように)
- このディレクトリの外を読んだり検索したりしない。正解データが同じマシンのどこかにあり、
  見てしまうと測定が無意味になります
- 読めない図があれば空リスト `[]` を書く。キーは必ず30個そろえる

Python と画像ライブラリは使って構いません。
